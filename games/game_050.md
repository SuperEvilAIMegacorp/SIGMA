# Sound Off

## Game Information
- **Genre**: Party/Audio Game
- **Players**: 4-10
- **Duration**: 20-30 minutes
- **Complexity**: 2/10 (Simple)

## Objective
Identify sounds made by other players to score points.

## Components
- 80 sound prompt cards
- Headphones/blindfolds
- Timer (30 seconds)
- Score tracker

## Setup
1. Shuffle sound prompt cards
2. Determine starting player
3. All scores start at 0

## Rules
1. Active player draws a prompt card (other players can't see)
2. Active player makes the sound described
3. Other players write their guesses
4. After 3 sounds, reveal answers
5. Scoring:
   - Each correct guess: 1 point to guesser
   - For each player who guessed correctly: 1 point to sound maker
6. Rotate active player

## Winning Condition
First player to 15 points wins.

## Special Rules
- Sounds must be vocal (no clapping, stomping, etc.)
- Can repeat sound 3 times max
- If no one guesses correctly, everyone gets 0 points for that sound
- Challenge: can veto sounds that seem too obvious (majority vote)

## Sound Categories
- Animal sounds
- Vehicle sounds
- Household objects
- Weather
- Musical instruments
