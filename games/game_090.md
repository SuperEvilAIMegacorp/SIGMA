# Syntax Error

## Game Information
- **Genre**: Programming Puzzle
- **Players**: 2-4
- **Duration**: 30-40 minutes
- **Complexity**: 7/10 (Complex)

## Objective
Debug and complete code snippets faster than opponents to score points.

## Components
- 60 code challenge cards (various programming tasks)
- Bug tokens (showing common errors)
- Syntax reference sheets
- Timer (3 minutes per challenge)
- Compiler tokens (limited help)

## Setup
1. Shuffle code challenge deck by difficulty
2. Each player gets 2 compiler tokens
3. Reference sheets available to all
4. Randomly determine starting player

## Rules
1. **Challenge Phase:**
   - Reveal code challenge card showing buggy code
   - Bug types:
     * Syntax errors (missing semicolons, brackets)
     * Logic errors (wrong operators, off-by-one)
     * Type errors (wrong variable types)
     * Runtime errors (division by zero, null references)
2. **Debug Phase:**
   - Players race to find all bugs (usually 3-5 per challenge)
   - Write corrections on paper
   - First to finish correctly wins round
3. **Verification Phase:**
   - Check solution against answer key
   - Correct: score points equal to difficulty (1-5)
   - Incorrect: identify missed bugs, no points

## Winning Condition
First to 25 points OR most points after 12 challenges.

## Special Rules
- **Compiler Tokens:**
  - Spend 1 token to get hint (points to line with bug)
  - Spend 2 tokens to auto-fix one bug
- **Challenge Difficulties:**
  - Beginner (1 point): obvious syntax errors
  - Intermediate (2-3 points): logic errors, multiple bugs
  - Advanced (4-5 points): subtle bugs, complex interactions
- **Languages:**
  - Simplified pseudocode (accessible to non-programmers)
  - Optional: real languages (Python, JavaScript, Java)
- **Time Bonus:**
  - Solve in <1 minute: +1 bonus point
  - Solve in <2 minutes: +0.5 bonus point

## Challenge Categories
- Array manipulation
- Loop conditions
- Function calls
- Conditional statements
- Variable scope
- String operations

## Educational Value
- Learn debugging skills
- Pattern recognition
- Attention to detail
- Common programming mistakes
