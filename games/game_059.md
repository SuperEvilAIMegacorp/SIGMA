# Debate Club

## Game Information
- **Genre**: Argumentation Game
- **Players**: 4-8 (even number)
- **Duration**: 40-50 minutes
- **Complexity**: 4/10 (Medium)

## Objective
Win debates by making compelling arguments and swaying the audience.

## Components
- 60 debate topic cards
- Position cards (For/Against)
- Audience voting tokens
- Argument strength cards
- Rebuttal tokens
- Time tracker

## Setup
1. Divide into two teams
2. Shuffle debate topics
3. Non-debaters form audience
4. Each team draws 3 argument strength cards

## Rules
1. **Topic Selection:** Reveal one topic card
2. **Position Assignment:** Teams randomly draw For or Against
3. **Preparation:** 2 minutes to strategize
4. **Debate Structure:**
   - Opening statements (1 min each)
   - Rebuttals (1 min each)
   - Closing statements (30 sec each)
5. **Audience Vote:**
   - Audience members vote for winner
   - Winning team scores points equal to vote margin
6. Rotate debaters and audience members

## Winning Condition
Team with most points after all players have debated twice wins.

## Special Rules
- Argument strength cards provide bonus points if used correctly
- Rebuttal tokens allow extra 30-second response
- Logic foul: audience can call out logical fallacies (nullifies argument)
- Charm bonus: especially entertaining arguments get +1 audience vote

## Debate Topics
- Serious: policy issues, philosophical questions
- Light: silly hypotheticals, preference debates
