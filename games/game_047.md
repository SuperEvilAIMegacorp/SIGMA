# Shadow Market

## Game Information
- **Genre**: Hidden Information Trading
- **Players**: 3-5
- **Duration**: 35-45 minutes
- **Complexity**: 6/10 (Medium-Complex)

## Objective
Accumulate wealth by trading in a market where values are partially hidden.

## Components
- 60 commodity cards (6 types, values hidden)
- Price revelation track
- Trading tokens
- Information tokens (3 per player)
- Final market value cards (sealed)

## Setup
1. Distribute random commodity cards to players (8 each)
2. Seal true values in envelopes
3. Only partial information visible (category and rarity)
4. Each player starts with 50 coins

## Rules
1. **Trading Phase:**
   - Propose trades with other players
   - Can trade commodities and/or coins
   - Both must agree
2. **Information Phase:**
   - Spend information token to peek at one card's true value
   - Can share (truthfully or lie) with others
3. **Market Phase:**
   - One commodity type's values partially revealed (everyone sees)
4. Play 8 rounds, then final reveal

## Winning Condition
Most total wealth (commodities at true value + remaining coins).

## Special Rules
- Can't show cards to others (must describe)
- Some commodities have negative value (liabilities)
- Insider info: some players start knowing certain values
- Market manipulation: spend 10 coins to influence revelation order
