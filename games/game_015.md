# Stack Attack

## Game Information
- **Genre**: Dexterity Game
- **Players**: 2-4
- **Duration**: 10-15 minutes
- **Complexity**: 1/10 (Simple)

## Objective
Remove blocks from the tower without toppling it.

## Components
- 54 wooden blocks (uniform size)
- Tower building template

## Setup
1. Build tower: 18 levels, 3 blocks per level, alternating directions
2. Tower building template shows starting configuration

## Rules
1. On your turn, remove one block from any level below the top completed level
2. Place removed block on top of tower perpendicular to previous level
3. Complete the top level before starting a new one
4. Use only one hand to remove and place blocks
5. Wait for tower to settle before next player's turn (count to 3)

## Winning Condition
Last player to successfully place a block before the tower falls wins.

## Special Rules
- If tower falls during your turn, you lose
- You cannot touch other blocks while removing your chosen block
