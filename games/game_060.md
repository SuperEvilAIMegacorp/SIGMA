# Clockwork Kingdom

## Game Information
- **Genre**: Resource Engine Building
- **Players**: 2-4
- **Duration**: 60-90 minutes
- **Complexity**: 8/10 (Complex)

## Objective
Build the most efficient clockwork automation engine to generate victory points.

## Components
- Gear cards (50 types, various effects)
- Engine board (per player)
- Resource tokens (5 types)
- Connection pins
- Turn tracker (12 rounds)
- Blueprint cards (showing gear combos)

## Setup
1. Each player gets blank engine board
2. Shuffle gear deck
3. Reveal 5 gears in market
4. Each player starts with 3 basic gears and 10 resources

## Rules
1. **Purchase Phase:**
   - Buy gears from market (cost in resources)
   - Replenish market immediately
2. **Building Phase:**
   - Place gear on your engine board
   - Connect to existing gears with pins
   - Connected gears can transfer resources/effects
3. **Activation Phase:**
   - Activate your engine (all connected gears trigger)
   - Generate resources based on gear effects
   - Chains multiply effects
4. **Scoring Phase:**
   - Complete blueprints for VP
   - Efficient engines score bonus VP

## Winning Condition
Most VP after 12 rounds.

## Special Rules
- Gears have input/output types (must match to connect)
- Gear types:
  - **Generators:** produce resources
  - **Converters:** transform resources
  - **Multipliers:** double adjacent gear output
  - **Storages:** save resources for later
- Engine optimization: longer chains = exponential bonuses
- Can dismantle gears (lose half value)
- Blueprint cards show optimal configurations (worth 10-30 VP each)
