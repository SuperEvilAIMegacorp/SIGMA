# Escape Room: Card Edition

## Game Information
- **Genre**: Cooperative Puzzle
- **Players**: 1-4
- **Duration**: 30-45 minutes
- **Complexity**: 6/10 (Medium-Complex)

## Objective
Work together to solve puzzles and escape before time runs out.

## Components
- 60 puzzle cards (8 puzzle chains)
- Hint cards (3 per puzzle chain)
- Timer (45 minutes)
- Answer key (sealed)

## Setup
1. Choose difficulty and arrange corresponding puzzle cards
2. Set timer to 45 minutes
3. Read introduction card

## Rules
1. Players work together examining cards
2. Solve puzzles to reveal codes/numbers
3. When you think you've solved a puzzle, check answer key
4. Correct answer unlocks next puzzle card in chain
5. Use hints if stuck (1-minute penalty per hint)
6. Must solve all 8 puzzle chains to escape

## Winning Condition
Team escapes if all puzzles solved before timer expires.

## Special Rules
- Puzzles can be solved in any order, but each chain is sequential
- Some puzzles require combining information from multiple cards
- Communication is key—discuss freely

## Puzzle Types
- Pattern recognition
- Cipher decoding
- Logic grids
- Spatial reasoning
