# Circuit Breaker

## Game Information
- **Genre**: Network Puzzle
- **Players**: 2-4
- **Duration**: 25-35 minutes
- **Complexity**: 6/10 (Medium-Complex)

## Objective
Complete your electrical circuit while disrupting opponents' circuits.

## Components
- 4 circuit boards (one per player)
- Wire tokens (straight, corner, junction)
- Power source tokens
- Capacitor cards (special abilities)
- Resistance dice

## Setup
1. Each player receives a circuit board with start and end nodes
2. Draw 5 wire tokens
3. Shuffle capacitor deck
4. Place power sources

## Rules
1. **Building Phase:**
   - Place 1-2 wire tokens on your board
   - Wires must connect orthogonally
   - Goal: connect power source to all end nodes
2. **Action Phase:**
   - Play capacitor card for special ability, or
   - Draw 2 new wire tokens
3. **Sabotage Phase (optional):**
   - Roll resistance die
   - On 5-6: remove one opponent wire token

## Winning Condition
First to create complete circuit connecting all nodes wins.

## Special Rules
- Junctions split current to multiple paths
- Short circuits (closed loops) cost you a turn to fix
- Capacitor abilities: skip opponent turn, shield from sabotage, swap wire tokens
- Advanced: variable resistance (some paths cost more tokens)

## Board Elements
- Start node (power source): 1 per board
- End nodes (destination): 4-6 per board
- Obstacles: can't place wires there
