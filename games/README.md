# Fictional Games Collection

## Overview
This collection contains 100 fictional games across various genres with varying levels of complexity. These games are designed for rule induction reasoning tasks, where models must observe game scenarios and deduce the underlying rules.

## Purpose
These games serve as a dataset for testing:
- **Inductive reasoning**: Inferring general rules from specific observations
- **Abductive reasoning**: Finding the best explanation for observed scenarios
- **Pattern recognition**: Identifying game mechanics and constraints
- **Logical deduction**: Understanding rule interactions and edge cases

## Complexity Distribution
- **Simple (1-3/10)**: ~35 games - Easy to learn, straightforward rules
- **Medium (4-6/10)**: ~40 games - Moderate complexity, some strategic depth
- **Complex (7-10/10)**: ~25 games - Intricate rules, deep strategic thinking required

## Genre Variety
The collection includes:
- **Card Games**: Traditional and innovative card mechanics
- **Board Games**: Abstract strategy, territory control, racing
- **Dice Games**: Probability and push-your-luck mechanics
- **Party Games**: Social deduction, communication, creativity
- **Strategy Games**: Resource management, engine building, tactical combat
- **Puzzle Games**: Logic problems, spatial reasoning, pattern matching
- **Cooperative Games**: Team-based objectives and challenges
- **Deduction Games**: Hidden information and mystery solving
- **Word Games**: Vocabulary and linguistic challenges
- **Trading Games**: Economics, negotiation, and market dynamics
- **Memory Games**: Recall and pattern recognition
- **Dexterity Games**: Physical skill challenges
- **Auction Games**: Bidding and valuation mechanics

## Game Files
All games are documented in individual markdown files (`game_001.md` through `game_100.md`).

Each game includes:
- **Game Name**: Unique identifier
- **Genre**: Category/type of game
- **Players**: Recommended player count
- **Duration**: Expected play time
- **Complexity**: Difficulty rating (1-10)
- **Objective**: Win condition and goals
- **Components**: Required game pieces
- **Setup**: Initial game state
- **Rules**: Complete gameplay mechanics
- **Winning Condition**: How to win
- **Special Rules**: Edge cases and variants

## Usage for Rule Induction
1. **Generate scenarios**: Simulate games using the rules
2. **Present observations**: Show game states and legal moves to models
3. **Test deduction**: Ask models to infer the rules from scenarios
4. **Verify understanding**: Check if inferred rules match actual rules
5. **Evaluate complexity**: Test how rule complexity affects inference accuracy

## Key Features
- **Varying rule complexity**: From simple matching games to multi-layered strategy
- **Different interaction types**: Simultaneous vs turn-based, competitive vs cooperative
- **Hidden vs open information**: Tests different reasoning requirements
- **Deterministic vs probabilistic**: Both dice-based and pure strategy games
- **Modular mechanics**: Many games combine multiple subsystems

## Example Use Cases
- Training AI to learn game rules from examples
- Testing causal reasoning capabilities
- Evaluating counterfactual thinking
- Assessing compositional reasoning (how rules interact)
- Benchmarking minimum description length finding (simplest rule set)
