# Binary Battlefield

## Game Information
- **Genre**: Abstract Strategy
- **Players**: 2
- **Duration**: 20-25 minutes
- **Complexity**: 7/10 (Complex)

## Objective
Control the binary grid by creating winning bit patterns.

## Components
- 8x8 binary grid board
- Binary tokens (0s and 1s in two colors)
- Pattern objective cards (showing target binary sequences)
- Bit-flip tokens (limited)
- Score tracker

## Setup
1. Empty board
2. Each player gets 32 tokens (16 zeros, 16 ones) in their color
3. Draw 5 objective cards (shared goals)
4. Each player gets 3 bit-flip tokens

## Rules
1. On your turn:
   - Place one token (0 or 1) on any empty space, OR
   - Use bit-flip token to flip opponent's token (0↔1, keeps their color)
2. After placement, check for completed objectives:
   - Row/column/diagonal patterns
   - Binary number sequences
   - Symmetric patterns
3. First to complete objective claims it (one-time scoring)

## Objectives Examples
- **"Binary 101":** Get sequence 1-0-1 in any row/column (5 points)
- **"Powers of Two":** Control spaces whose positions are powers of 2 (8 points)
- **"Checkboard":** 4x4 alternating 0-1 pattern (10 points)
- **"Palindrome":** Create binary palindrome in any line (7 points)
- **"Majority":** Have more tokens in 5 consecutive spaces (6 points)

## Winning Condition
First to 30 points OR most points when board is full.

## Special Rules
- **Binary Operations:**
  - Some objectives require logical operations (AND, OR, XOR)
  - Example: "XOR Row" - row where XOR of all bits equals 1
- **Blocking:**
  - Can sacrifice points to block opponent objectives
- **Token Conservation:**
  - Limited tokens force strategic choices (0 vs 1)
- **Bit-Flip Strategy:**
  - Using bit-flip on opponent can:
    * Disrupt their pattern
    * Complete your pattern
    * Maintain color control

## Advanced Mechanics
- Some objectives worth more if completed with all same value (all 0s or all 1s)
- Cascade scoring: completing one objective can enable another
- Board zones: different regions have multipliers

## Strategic Depth
- Pattern recognition
- Dual-purpose moves (build + block)
- Resource management (0 vs 1 tokens)
- Bit-flip timing
- Objective prioritization
- Positional control

## Educational Value
- Binary number system
- Logical operations
- Pattern matching
- Computational thinking
