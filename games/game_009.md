# Word Builder

## Game Information
- **Genre**: Word Game
- **Players**: 2-6
- **Duration**: 15-20 minutes
- **Complexity**: 2/10 (Simple)

## Objective
Score the most points by creating the longest words.

## Components
- 100 letter tiles (standard Scrabble distribution)
- Score sheet

## Setup
1. Place all tiles face-down in center
2. Each player draws 7 tiles
3. Determine starting player

## Rules
1. On your turn, use any of your letters to make one word (minimum 3 letters)
2. Score 1 point per letter used
3. Draw back up to 7 tiles
4. Play passes clockwise

## Winning Condition
When tiles run out, player with most points wins.

## Special Rules
- Each word can only be played once per game (all players)
- Challenge: If challenged and word is invalid, lose your turn
