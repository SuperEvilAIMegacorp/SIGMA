# Viral Vector

## Game Information
- **Genre**: Area Control
- **Players**: 2-4
- **Duration**: 30-40 minutes
- **Complexity**: 6/10 (Medium-Complex)

## Objective
Spread your virus across the network to infect the most nodes.

## Components
- Network board (50 nodes connected by links)
- Virus tokens (4 colors, 20 each)
- Mutation cards (30)
- Immunity tokens
- Infection tracker

## Setup
1. Each player places 1 virus token on a random node (starting infections)
2. Shuffle mutation deck
3. Randomly place 5 immunity tokens on nodes
4. Draw 3 mutation cards per player

## Rules
1. **Infection Phase:**
   - Choose one infected node (has your virus)
   - Spread to all adjacent nodes (along links)
   - If node is empty: place your virus
   - If node has different virus: compete (see combat)
   - If node has immunity: blocked
2. **Mutation Phase:**
   - Play 0-1 mutation card for special ability
   - Draw back to 3 cards
3. **Resolution Phase:**
   - Remove overcrowded nodes (5+ different viruses = all destroyed)

## Combat System
When viruses compete for a node:
- Each virus owner rolls d6 + virus count at adjacent nodes
- Higher result wins, takes the node
- Loser's virus removed

## Winning Condition
Control 25+ nodes OR eliminate all other viruses.

## Special Rules
- **Mutation Cards:**
  - Super spreader: infect 2 hops away
  - Immunity bypass: ignore immunity tokens
  - Rapid spread: infect twice in one turn
  - Resistance: +3 to combat rolls
  - Dormancy: hide virus from attacks
- **Network Topology:**
  - Hub nodes (highly connected): valuable but contested
  - Isolated nodes: safe but low spread potential
- **Immunity:**
  - Naturally occurring (initial placement)
  - Can be earned by controlling medical nodes
- **Quarantine:**
  - Spend 2 viruses to cut a link (prevent spread through that connection)

## Strategic Elements
- Network positioning (control hubs)
- Mutation timing
- Expansion vs consolidation
- Defensive positioning
- Quarantine placement
