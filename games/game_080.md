# Molecule Mayhem

## Game Information
- **Genre**: Pattern Matching
- **Players**: 2-4
- **Duration**: 20-25 minutes
- **Complexity**: 4/10 (Medium)

## Objective
Build the most valuable molecular structures from atom cards.

## Components
- 80 atom cards (H, C, O, N with valence numbers)
- Bond tokens (single, double, triple)
- Molecule reference guide
- Score tracker

## Setup
1. Shuffle atom deck
2. Each player draws 7 cards
3. Pool bond tokens
4. Reference guide visible to all

## Rules
1. On your turn:
   - Play atoms to build molecules
   - Connect with appropriate bonds (respecting valence rules)
   - Must create stable, valid molecules
2. **Valence Rules:**
   - H: 1 bond
   - C: 4 bonds
   - O: 2 bonds
   - N: 3 bonds
3. Score completed molecules:
   - Simple (2-3 atoms): 2 points
   - Moderate (4-6 atoms): 5 points
   - Complex (7+ atoms): 10 points
   - Special molecules (from reference): bonus points

## Winning Condition
First to 30 points wins.

## Special Rules
- Can extend existing molecules (yours or opponents' with permission)
- Functional groups (OH, NH₂, COOH) have bonus values
- Organic chemistry: carbon chains worth more
- Reaction cards: transform molecules (break/reform bonds)
- Invalid molecule: lose turn, discard cards used

## Example Molecules
- Water (H₂O): 2 points
- Methane (CH₄): 3 points
- Ethanol (C₂H₅OH): 8 points
- Glucose (C₆H₁₂O₆): 15 points

## Educational Value
- Learn basic chemistry
- Understand molecular bonding
- Recognize common compounds
- Strategic: balance simplicity vs complexity
