# Logic Labyrinth

## Game Information
- **Genre**: Puzzle Racing
- **Players**: 2-4
- **Duration**: 30-40 minutes
- **Complexity**: 7/10 (Complex)

## Objective
Navigate through logic puzzle rooms faster than opponents to reach the exit.

## Components
- Modular puzzle room tiles (30)
- Player pawns
- Logic puzzle cards (60)
- Solution tokens
- Timer (5 minutes per puzzle)
- Skip tokens (2 per player)

## Setup
1. Arrange 10 random room tiles in a path to exit
2. Each room has one logic puzzle
3. Players start at entrance
4. Shuffle puzzle deck

## Rules
1. **Puzzle Phase:**
   - Active player enters room
   - Draws and attempts puzzle card
   - Has 5 minutes to solve
   - Can use skip token (move to next room without solving)
2. **Solution Phase:**
   - If correct: advance to next room
   - If incorrect: stay in room, next player's turn
   - Can retry same puzzle on your next turn
3. **Other Players:**
   - Can work on their current puzzle while waiting
   - First to solve advances

## Puzzle Types
1. **Logic Grids:** Assign attributes using clues
2. **Number Sequences:** Find pattern, predict next
3. **Knight's Tour:** Chess piece path problems
4. **Boolean Circuits:** Determine output from logic gates
5. **River Crossing:** Classic constraint puzzles
6. **Sudoku Variants:** Filling grids with constraints

## Winning Condition
First player to reach exit room AND solve final boss puzzle.

## Special Rules
- Room effects: some rooms have special modifiers
  - Time pressure: 3-minute limit
  - Partial help: first clue revealed
  - Team room: all players solve together
- Hint system: spend 1 minute for one hint
- Difficulty scaling: later rooms have harder puzzles
- Boss puzzle: combines multiple puzzle types, 10-minute limit

## Strategic Elements
- Skip token timing (save for hard puzzles vs use early)
- Puzzle type preferences
- Time management
- Risk assessment (attempt vs skip)
