# Resource Empire

## Game Information
- **Genre**: Resource Management
- **Players**: 2-4
- **Duration**: 45-60 minutes
- **Complexity**: 7/10 (Complex)

## Objective
Build the most prosperous empire by managing resources efficiently.

## Components
- Game board with resource nodes
- 4 resource types (wood, stone, gold, food)
- Building cards (15 types)
- Worker meeples (8 per player)
- Resource tokens

## Setup
1. Each player starts with 2 workers and 3 of each resource
2. Shuffle building cards into deck
3. Reveal 5 building cards face-up
4. Randomly place resource nodes on board

## Rules
1. Rounds consist of 3 phases: Placement, Harvesting, Building
2. **Placement**: Place workers on resource nodes (max 1 per node)
3. **Harvesting**: Collect resources where you have workers
4. **Building**: Spend resources to buy face-up buildings (replenish immediately)
5. Buildings provide ongoing bonuses or victory points
6. Play 12 rounds

## Winning Condition
Most victory points from buildings and leftover resources (each 5 resources = 1 VP).

## Special Rules
- Some buildings let you place multiple workers on nodes
- Gold is wild and can substitute for any resource
- Some buildings chain together for multiplier effects
