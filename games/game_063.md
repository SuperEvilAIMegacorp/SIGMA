# Quantum Entanglement

## Game Information
- **Genre**: Abstract Strategy
- **Players**: 2
- **Duration**: 25-35 minutes
- **Complexity**: 7/10 (Complex)

## Objective
Control more entangled pairs than opponent when board is full.

## Components
- 8x8 grid board
- 32 quantum tokens per player (each has entanglement number 1-16, two of each)
- Measurement cards
- Superposition markers

## Setup
1. Empty board
2. Each player takes their 32 tokens
3. Shuffle measurement deck

## Rules
1. On your turn, place one token on empty space
2. If you place a token with same number as one already on board:
   - They become entangled (linked pair)
   - Place superposition marker on both
   - Entangled pairs score together
3. When both tokens in an entangled pair are placed:
   - Draw measurement card
   - Card determines which token "collapses" (becomes primary)
   - Primary token's position determines scoring zone

## Winning Condition
Most points from entangled pairs after all tokens placed.

## Special Rules
- Scoring zones: corners worth 3, edges worth 2, center worth 1
- Can block opponent's entanglement by placing on strategic space
- Measurement cards have probabilities (some weighted)
- Multiple entanglements: if 3+ same numbers, all entangle (complex scoring)
- Wave function: some tokens affect adjacent spaces

## Strategic Depth
- Probability management
- Spatial positioning
- Entanglement timing
- Defensive blocking
