# Witness Testimony

## Game Information
- **Genre**: Social Deduction
- **Players**: 5-8
- **Duration**: 30-40 minutes
- **Complexity**: 5/10 (Medium)

## Objective
Reconstruct the true sequence of events while some players have false memories.

## Components
- 50 event cards (what happened)
- 8 role cards (witness roles)
- Timeline board (10 slots)
- Memory reliability tokens
- Truth tracker

## Setup
1. Create secret true timeline (10 events in order)
2. Deal role cards:
   - 3-4 Honest Witnesses (saw true events)
   - 2-3 Confused Witnesses (some false memories)
   - 1 Fabricator (deliberately lying)
3. Give each player partial information about timeline

## Rules
1. **Testimony Phase:**
   - Each player shares what they "remember" (2 minutes each)
   - Honest witnesses tell truth about events they saw
   - Confused witnesses have 2-3 false memories mixed in
   - Fabricator invents details
2. **Deliberation Phase:**
   - Group discusses inconsistencies (5 minutes)
   - Try to identify who's reliable
3. **Reconstruction Phase:**
   - Group places events on timeline
   - Majority vote for each position
4. **Reveal Phase:**
   - Show true timeline
   - Score based on accuracy

## Winning Condition
**Cooperative:** 8+ correct event placements = team wins
**Points:** Correct identifications of roles + timeline accuracy

## Special Rules
- Honest witnesses only know 4-5 events (not complete picture)
- Confused witnesses believe their false memories are true
- Fabricator wins if ≥6 events placed incorrectly
- Memory reliability tokens: spend to challenge testimony
- Cross-examination: can ask questions to test consistency

## Strategic Elements
- Pattern detection (who's consistent?)
- Logical deduction (which sequence makes sense?)
- Social reading (who's acting suspicious?)
- Information synthesis (combine partial testimonies)
