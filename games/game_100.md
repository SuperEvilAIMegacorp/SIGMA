# Quantum Heist

## Game Information
- **Genre**: Cooperative Strategy
- **Players**: 2-4
- **Duration**: 60-90 minutes
- **Complexity**: 9/10 (Very Complex)

## Objective
Execute a heist in a quantum-state building where rooms exist in superposition until observed.

## Components
- Modular building tiles (30, double-sided)
- Character cards (4 specialists)
- Quantum state tokens
- Observation cards
- Security level tracker
- Probability dice (custom)
- Loot objective cards
- Equipment deck

## Setup
1. Build quantum building: arrange tiles face-down (unknown states)
2. Each player chooses specialist
3. Security level starts at 2
4. Draw loot objectives (must steal 3 specific items)
5. Each player draws 3 equipment cards

## Rules
**Quantum Mechanics:**
- Rooms exist in superposition (multiple possible states) until observed
- When you enter a room, roll probability dice to "collapse" its state
- Room becomes one of: Empty, Guarded, Trapped, Contains Loot, Security Hub

**Turn Structure:**
1. **Planning Phase:**
   - Team discusses strategy (2 minutes)
   - Decide who moves where
2. **Action Phase:**
   - Each specialist takes 3 actions:
     * Move to adjacent room
     * Observe room (collapse quantum state)
     * Use equipment
     * Disable security
     * Extract loot
3. **Security Phase:**
   - Roll security dice
   - Security level may increase
   - At level 10, heist fails
4. **Quantum Shift Phase:**
   - Unobserved rooms may change states (10% chance each)

## Specialists
- **The Ghost:** Can observe without collapsing (once per game)
- **The Hacker:** Reduce security level remotely
- **The Muscle:** Better at disabling guards
- **The Infiltrator:** Extra movement, can reroll observations

## Winning Condition
Team succeeds if they collect all 3 loot objectives and reach exit before:
- Security level hits 10, OR
- Any specialist caught, OR
- 20 turns elapse

## Special Rules
- **Superposition Planning:**
  - Can plan for multiple possible room states
  - Equipment lets you influence probability of collapsed states
- **Entanglement:**
  - Some rooms are entangled (collapsing one affects other)
  - Must track entanglement chains
- **Observation Paradox:**
  - The more you observe, the higher security rises
  - Must balance knowledge vs stealth
- **Quantum Tunneling:**
  - Special equipment lets you pass through walls (ignores room states)
  - Very limited uses
- **Decoherence:**
  - Observed rooms slowly return to superposition if not monitored
  - Creates dynamic, shifting layout

## Complexity Factors
- Probability management (multiple possible states)
- Path planning under uncertainty
- Resource optimization (limited observations)
- Team coordination
- Risk assessment
- Quantum mechanics understanding (simplified but present)

## Strategic Depth
- When to observe vs move blindly
- Equipment timing
- Specialist positioning
- Security management
- Contingency planning (multiple state outcomes)
- Entanglement exploitation

## Advanced Mechanics
- **Observer Effect:** Observing a room alerts nearby guards (ripple effect)
- **Quantum Lockpicking:** Some safes require observing in specific order
- **Schrodinger's Vault:** Final objective exists in all states until last moment
- **Timeline Splitting:** Can "branch" timeline to try different approaches (limited)

## Educational Value
- Quantum superposition concepts
- Probability theory
- Decision making under uncertainty
- Systems thinking
- Risk analysis

## Replayability
- Randomized building layouts
- Variable loot locations
- Different specialist combinations
- Adjustable difficulty (starting security level)
- Multiple approaches to solve puzzles
