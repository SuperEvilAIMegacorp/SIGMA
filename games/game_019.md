# Codebreaker

## Game Information
- **Genre**: Deduction Game
- **Players**: 2
- **Duration**: 15-20 minutes
- **Complexity**: 4/10 (Medium)

## Objective
Deduce your opponent's secret code before they deduce yours.

## Components
- Code pegs: 6 colors (8 of each)
- Guess board with 10 rows
- Feedback pegs: black and white

## Setup
1. Each player secretly creates a 4-peg code using any colors (colors can repeat)
2. Players place their code behind their shield

## Rules
1. Players simultaneously make guesses about opponent's code
2. After each guess, opponent gives feedback:
   - Black peg: correct color in correct position
   - White peg: correct color in wrong position
3. No feedback: no correct colors
4. Continue guessing until someone breaks the code

## Winning Condition
First player to guess opponent's exact code wins.

## Special Rules
- Feedback pegs don't indicate which positions are correct
- You must give accurate feedback
- Maximum 10 guesses (if both exceed 10, most black pegs on round 10 wins)
