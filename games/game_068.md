# Fractal Forest

## Game Information
- **Genre**: Tile Placement
- **Players**: 2-4
- **Duration**: 35-45 minutes
- **Complexity**: 6/10 (Medium-Complex)

## Objective
Create the most valuable fractal patterns by placing tree tiles.

## Components
- 80 tree tiles (4 sizes: seedling, sapling, tree, ancient)
- Pattern recognition chart
- Score multiplier tokens
- Forest board (hexagonal grid)

## Setup
1. Shuffle tiles by size (4 separate decks)
2. Each player draws 2 seedlings, 1 sapling
3. Randomly place 3 ancient trees on board as starting points

## Rules
1. On your turn:
   - Place 1 tile adjacent to existing tile
   - Tile must match at least one edge (tree type or size)
2. Draw replacement tile from any size deck
3. When you create a fractal pattern (self-similar at different scales):
   - Score points based on pattern complexity
   - Larger fractals worth exponentially more

## Fractal Patterns
- **Simple:** 3 tiles in same shape at different scales (3 points)
- **Complex:** 7+ tiles with recursive structure (10+ points)
- **Perfect:** Exact self-similarity across 3 scales (25 points)

## Winning Condition
Most points when board fills or tile decks empty.

## Special Rules
- Ecosystem bonuses: diverse tree types in pattern = +5 points
- Ancient trees act as wildcard matches
- Can sacrifice turn to swap 3 tiles
- Blocking: strategic placement can prevent opponent fractals
- Seasonal modifier: some rounds favor certain tree types

## Strategic Elements
- Pattern planning
- Resource management (which deck to draw from)
- Spatial awareness
- Opponent disruption
