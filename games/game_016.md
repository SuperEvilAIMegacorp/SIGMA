# Truth or Bluff

## Game Information
- **Genre**: Bluffing Game
- **Players**: 3-6
- **Duration**: 20-30 minutes
- **Complexity**: 3/10 (Simple-Medium)

## Objective
Score points by correctly identifying truths and bluffs.

## Components
- 100 statement cards (mix of true/false facts)
- Player voting tokens (Truth/Bluff for each player)
- Score tracker

## Setup
1. Shuffle statement cards
2. Each player gets Truth and Bluff voting tokens
3. Set score tracker to 0 for all players

## Rules
1. Active player draws and reads a statement card out loud
2. Active player decides to present it as truth or bluff (regardless of what it actually is)
3. All other players secretly choose their voting token
4. Reveal votes simultaneously
5. Reveal card answer:
   - If player presented it correctly (truth as truth, false as bluff): +2 points
   - Each voter who guessed correctly: +1 point
6. Rotate active player clockwise

## Winning Condition
First player to 15 points wins.

## Special Rules
- Active player can embellish the statement but not change core facts
- Tied players share victory
