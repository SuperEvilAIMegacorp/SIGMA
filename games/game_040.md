# Prophecy Cards

## Game Information
- **Genre**: Prediction Game
- **Players**: 3-6
- **Duration**: 20-25 minutes
- **Complexity**: 3/10 (Simple-Medium)

## Objective
Score points by accurately predicting game outcomes.

## Components
- 60 event cards (various game scenarios)
- Prediction tokens (numbered 1-10)
- Score tracker
- Outcome dice

## Setup
1. Shuffle event deck
2. Each player gets full set of prediction tokens (1-10)
3. Set scores to 0

## Rules
1. Reveal one event card (e.g., "Two players will flip coins - predict total heads")
2. All players secretly select a prediction token
3. Reveal predictions simultaneously
4. Execute the event
5. Players who predicted correctly score points:
   - Exact prediction: 3 points
   - Off by 1: 1 point
6. Used tokens go to discard (return all tokens after 10 rounds)

## Winning Condition
Most points after 15 event cards wins.

## Special Rules
- Prediction tokens can only be used once per cycle
- Some events have multiple prediction points
- Bonus: three exact predictions in a row = +5 bonus points
