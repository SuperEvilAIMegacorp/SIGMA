# Relic Hunters

## Game Information
- **Genre**: Press-Your-Luck Adventure
- **Players**: 2-5
- **Duration**: 30-40 minutes
- **Complexity**: 4/10 (Medium)

## Objective
Collect the most valuable relics from expeditions without getting trapped.

## Components
- 60 expedition cards (relics, traps, clues)
- 5 artifact tokens (major relics)
- Explorer pawns
- Base camp board
- Risk dice

## Setup
1. Shuffle expedition deck
2. Place 5 face-up cards as current expedition
3. Each player starts at base camp
4. Place artifact tokens face-down

## Rules
1. **Decision Phase:** Choose to:
   - Continue deeper (draw another card)
   - Return to base camp (secure collected relics)
2. **Draw Phase:** If continuing, reveal next expedition card:
   - **Relic:** Add to collection (temporary, until you return)
   - **Trap:** Roll risk dice (5-6 = escape, 1-4 = lose all relics this expedition)
   - **Clue:** Reveal one face-down artifact token
3. **Return Phase:** If returning, add all collected relics to your score

## Winning Condition
First to 50 relic points OR collect 3 artifacts wins.

## Special Rules
- Relics have variable values (1-10 points)
- Artifacts worth 15 points each but require specific clues
- Trap accumulation: multiple traps = harder escape
- Equipment cards: bought with points, help avoid traps
- Other players can steal unguarded relics at base camp (risk vs reward)

## Risk Management
- Push too far = lose everything
- Return too early = minimal gains
- Balance greed vs safety
