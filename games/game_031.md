# Signal Towers

## Game Information
- **Genre**: Network Building
- **Players**: 2-4
- **Duration**: 30-40 minutes
- **Complexity**: 6/10 (Medium-Complex)

## Objective
Build the most valuable signal network by connecting towers.

## Components
- Hexagonal grid board (19 hexes)
- 40 tower pieces (10 per player)
- 60 connection tokens (3 lengths)
- Score tracker

## Setup
1. Empty board placed in center
2. Each player gets 10 towers
3. Connection tokens pooled nearby
4. Players choose starting hex (draft order)

## Rules
1. On your turn, either:
   - Place a tower on empty hex (costs 1 action)
   - Connect two of your towers with token (costs 2 actions)
2. You have 3 actions per turn
3. Connections score points based on:
   - Length (longer = more points)
   - Network size (towers in connected group)
   - Completed geometric patterns (triangles, hexagons)

## Winning Condition
After all towers placed, highest score wins.

## Special Rules
- Connections cannot cross other connections
- Bonus: connecting 6 towers in hexagon = 20 points
- Can spend actions to block opponent connections
- Maximum one tower per hex
