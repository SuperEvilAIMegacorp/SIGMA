# Category King

## Game Information
- **Genre**: Party Game
- **Players**: 3-8
- **Duration**: 20-30 minutes
- **Complexity**: 1/10 (Simple)

## Objective
Score points by naming items in categories faster than opponents.

## Components
- 100 category cards
- Timer (30 seconds)
- Letter die (26-sided)
- Score tracker

## Setup
1. Shuffle category cards
2. Determine starting player
3. Set score to 0 for all players

## Rules
1. Active player draws a category card (e.g., "Types of Fruit")
2. Roll letter die to determine starting letter
3. Active player starts timer and has 30 seconds to name items in that category starting with that letter
4. Score 1 point per valid item
5. Other players can challenge invalid items (lose that point if challenge succeeds)
6. Rotate active player clockwise

## Winning Condition
First player to 20 points wins.

## Special Rules
- No repeats from previous rounds of same category
- Other players keep mental track to challenge
- If letter die shows rare letter (Q, X, Z), re-roll
