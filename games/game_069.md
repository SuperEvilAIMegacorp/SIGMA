# Probability Court

## Game Information
- **Genre**: Logic/Deduction Game
- **Players**: 3-6
- **Duration**: 30-40 minutes
- **Complexity**: 6/10 (Medium-Complex)

## Objective
Solve cases by correctly assessing probability of guilt based on evidence.

## Components
- 30 case files (each with suspect and evidence cards)
- Probability tokens (0%, 25%, 50%, 75%, 100%)
- Evidence cards (alibi, motive, opportunity, forensics)
- Verdict tracker
- Judge gavel (turn indicator)

## Setup
1. Shuffle case files
2. Each player gets full set of probability tokens
3. One player starts as judge (rotates)

## Rules
1. **Case Presentation:**
   - Judge reveals case file with 3-5 pieces of evidence
   - Each evidence card has reliability rating (weak, moderate, strong)
2. **Deliberation:**
   - Players analyze evidence independently (3 minutes)
   - Calculate probability of guilt considering:
     * Evidence strength
     * Evidence reliability
     * Conflicting vs supporting evidence
3. **Verdict Submission:**
   - All players secretly select probability token
   - Reveal simultaneously
4. **Resolution:**
   - Judge reveals true probability (based on hidden answer key)
   - Closest estimate scores points: exact = 5, within 25% = 3, within 50% = 1
5. Rotate judge

## Winning Condition
Most points after all players have judged 2 cases each.

## Special Rules
- Bayesian reasoning bonus: show work for +2 points if exactly correct
- Probability paradoxes: some cases have counterintuitive solutions
- Evidence can be misleading (red herrings)
- Group deliberation mode: discuss before voting (changes dynamics)

## Evidence Types
- Direct (strong but can be falsified)
- Circumstantial (weak but cumulative)
- Character (very weak, biasing)
- Forensic (strong, probabilistic)
