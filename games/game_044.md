# Heist Crew

## Game Information
- **Genre**: Cooperative Strategy
- **Players**: 2-5
- **Duration**: 40-50 minutes
- **Complexity**: 7/10 (Complex)

## Objective
Work together to pull off the perfect heist without getting caught.

## Components
- Heist board (building layout)
- 5 crew member cards (different skills)
- 40 action cards
- Security tracker (increases over time)
- Loot tokens (various values)
- Alarm tokens

## Setup
1. Choose heist scenario (determines building layout and loot)
2. Each player selects a crew member
3. Security starts at level 2
4. Place loot tokens throughout building

## Rules
1. **Planning Phase:** Players discuss strategy (2 minutes)
2. **Action Phase:** Players simultaneously reveal action cards
3. **Resolution Phase:**
   - Execute actions in initiative order
   - Collect loot
   - Check security triggers
4. **Security Phase:**
   - Roll alarm dice
   - If alarm triggers, security level increases
   - At security level 10, heist fails

**Actions include:**
- Hack (bypass security)
- Sneak (move silently)
- Smash (force entry, loud)
- Distract (lower security temporarily)

## Winning Condition
Team escapes with target loot value before security reaches 10.

## Special Rules
- Each crew member has unique abilities
- Some rooms require multiple crew members
- Can abort heist early for partial rewards
- Communication forbidden during action phase
