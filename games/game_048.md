# Reaction Chain

## Game Information
- **Genre**: Real-Time Card Game
- **Players**: 2-6
- **Duration**: 15-20 minutes
- **Complexity**: 3/10 (Simple-Medium)

## Objective
Get rid of all your cards by completing reaction chains faster than opponents.

## Components
- 100 reaction cards (showing formulas like A+B→C)
- Element tokens
- Timer

## Setup
1. Shuffle reaction deck
2. Deal 10 cards to each player
3. Place element tokens in center pool

## Rules
1. When timer starts, all players play simultaneously
2. Play cards that form valid chains:
   - If you play A+B→C, take elements A and B from pool, add C to pool
   - Next player can use C in their reaction
3. Reactions must be scientifically valid (basic chemistry rules)
4. If pool doesn't have required elements, can't play that card
5. First to empty hand wins the round

## Winning Condition
Win 3 rounds to win game.

## Special Rules
- Catalysts: special cards that enable reactions without being consumed
- Chain bonus: 3+ card chain in sequence = +5 points
- Disputes: call timeout, majority vote determines validity
- Element pool starts with 5 random elements

## Example Chain
Player 1: H+H→H₂ (use 2 H tokens, add H₂ to pool)
Player 2: H₂+O→H₂O (use H₂ and O, add H₂O to pool)
