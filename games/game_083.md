# Gossip Network

## Game Information
- **Genre**: Information Trading
- **Players**: 4-8
- **Duration**: 30-40 minutes
- **Complexity**: 5/10 (Medium)

## Objective
Collect the most valuable secrets while trading gossip and managing your reputation.

## Components
- 80 gossip cards (various value and sensitivity levels)
- Reputation tracker (per player)
- Trust tokens
- Revelation cards (force secret disclosure)
- Score tracker

## Setup
1. Shuffle gossip deck
2. Deal 5 cards to each player (secret hand)
3. Each player starts with 10 reputation points
4. Each player gets 3 trust tokens

## Rules
1. **Trading Phase (3 minutes):**
   - Move around, offer gossip trades
   - Can trade: gossip cards, trust tokens, future favors
   - All trades voluntary (bilateral agreement)
2. **Revelation Phase:**
   - Draw revelation card (random player must reveal something)
   - Revealed gossip scored immediately
   - Reputation affected based on gossip sensitivity
3. **Reputation Check:**
   - If reputation ≤0, you're out (all gossip confiscated)
4. Play 6 rounds

## Winning Condition
Highest gossip value at end. Reputation acts as multiplier:
- 10+ rep: 2x gossip value
- 5-9 rep: 1x gossip value
- 1-4 rep: 0.5x gossip value

## Special Rules
- Gossip types:
  - Celebrity scandal (high value, low risk)
  - Political secret (medium value, medium risk)
  - Personal rumor (low value, high risk if false)
- Trust tokens:
  - Spend to verify gossip is true before trade
  - Protect from one revelation
  - Force someone to trade with you
- Bluffing: can lie about gossip value (if caught, -3 reputation)
- Alliances: form information-sharing partnerships

## Strategic Complexity
- Risk vs reward (valuable gossip = reputation danger)
- Trust management
- Bluffing and reading tells
- Portfolio diversification
- Timing revelations
