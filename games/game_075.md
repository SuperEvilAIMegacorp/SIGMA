# Encryption Wars

## Game Information
- **Genre**: Code Breaking
- **Players**: 2-4 (teams possible)
- **Duration**: 35-45 minutes
- **Complexity**: 7/10 (Complex)

## Objective
Decode opponent's encrypted messages while protecting your own.

## Components
- 60 cipher cards (different encryption methods)
- Message cards (100 short phrases)
- Decryption tools (frequency analysis, known plaintext, etc.)
- Encryption strength tracker
- Timer

## Setup
1. Each player draws 5 cipher cards
2. Each player draws 3 message cards
3. Set up encryption workspace
4. Randomly determine turn order

## Rules
1. **Encryption Phase:**
   - Choose one message to encrypt
   - Apply up to 3 ciphers in sequence
   - Submit encrypted message to opponent
2. **Decryption Phase:**
   - Receive opponent's encrypted message
   - Use decryption tools (limited uses)
   - Have 5 minutes to decode
3. **Scoring:**
   - Correctly decode opponent's message: +5 points
   - Your message stays encrypted: +3 points
   - Partial decode (50%+ correct): +2 points

## Cipher Types
- **Substitution:** letter replacement
- **Transposition:** letter reordering
- **Shift:** Caesar cipher (variable shift)
- **Polyalphabetic:** Vigenère-style
- **Binary:** convert to 0s and 1s with encoding

## Winning Condition
First to 20 points OR most points after 8 rounds.

## Special Rules
- Cipher stacking: multiple ciphers exponentially harder
- Decryption tools:
  - Frequency analysis (reveals common letters)
  - Known plaintext (if you know message format)
  - Brute force (try all possibilities for simple ciphers)
- Counter-intelligence: can intercept and read opponent communications
- Meta-game: learn opponent's cipher preferences

## Strategic Elements
- Balance encryption strength vs opponent's decryption skill
- Resource management (decryption tools)
- Pattern recognition
- Cryptanalysis techniques
