# Dream Weaver

## Game Information
- **Genre**: Storytelling/Memory Game
- **Players**: 3-6
- **Duration**: 30-40 minutes
- **Complexity**: 3/10 (Simple-Medium)

## Objective
Weave the most coherent dream narrative while remembering and building on others' contributions.

## Components
- 120 dream element cards (objects, people, places, emotions, symbols)
- Dream journal sheets
- Coherence tracker
- Voting tokens
- Surrealism dice

## Setup
1. Each player draws 5 dream element cards
2. One player designated as "Dreamer" (rotates each round)
3. Set coherence tracker to 10

## Rules
1. **Dream Start:**
   - Dreamer plays 1 card and narrates opening (30 seconds)
   - Sets the dream's initial tone and setting
2. **Dream Building:**
   - Going clockwise, each player:
     * Must recite all previous dream elements in order
     * Adds one new element from their hand
     * Narrates how it connects (30 seconds)
   - If you forget an element, roll surrealism dice:
     * 1-3: -1 coherence, continue
     * 4-6: Skip turn, draw new card
3. **Dream End:**
   - When coherence reaches 0 OR deck empty, dream ends
   - Dreamer gives closing narration
4. **Scoring:**
   - Vote on most memorable contribution: +3 points
   - Dreamer scores +2 if dream stayed coherent (ended with coherence >0)
   - Each element successfully integrated: +1 point

## Winning Condition
Most points after everyone has been Dreamer once.

## Special Rules
- Surrealism encouraged: weird transitions are fine if narrated well
- Challenge: players can challenge if element not mentioned (majority vote)
- Wild cards: "anything you want" elements (2 in deck)
- Nightmare mode: sudden events that change dream tone (event cards)

## Dream Elements Categories
- Objects (flying bicycle, melting clock)
- Characters (childhood friend, talking animal)
- Places (underwater castle, infinite library)
- Emotions (nostalgia, anxiety, joy)
- Symbols (keys, mirrors, doors)
