# Number Cascade

## Game Information
- **Genre**: Abstract Puzzle
- **Players**: 1-2
- **Duration**: 10-15 minutes
- **Complexity**: 4/10 (Medium)

## Objective
Arrange number tiles to create cascading sequences with highest score.

## Components
- 36 number tiles (1-9, four of each)
- 6x6 grid board
- Scoring reference card

## Setup
1. Shuffle tiles face-down
2. Each player draws 5 tiles (competitive mode)
3. Solo mode: draw all tiles randomly

## Rules
1. On your turn, place one tile on the grid
2. Tiles score when they form patterns:
   - **Ascending sequence:** +points equal to sequence length
   - **Descending sequence:** +points equal to sequence length
   - **Matching numbers adjacent:** +5 points per pair
3. Sequences can be horizontal, vertical, or diagonal
4. Draw new tile after placing

## Winning Condition
**Competitive:** Higher score after all tiles placed
**Solo:** Beat target score (100 points)

## Special Rules
- Cascades: If placing a tile creates multiple patterns, score all
- Bonus: sequences of 5+ numbers = double points
- Perfect grid (all tiles used in some pattern) = +20 bonus

## Example
Placing 5 between 4 and 6 creates ascending sequence (4-5-6) = 3 points
