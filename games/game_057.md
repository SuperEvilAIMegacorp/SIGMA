# Pixel Art Battle

## Game Information
- **Genre**: Creative Competition
- **Players**: 2-6
- **Duration**: 30-40 minutes
- **Complexity**: 3/10 (Simple-Medium)

## Objective
Score points by creating recognizable pixel art with limited pixels.

## Components
- 6x6 grid boards (one per player)
- Colored pixel tokens (5 colors, 50 of each)
- Theme cards (50)
- Timer (90 seconds)
- Voting tokens

## Setup
1. Each player gets a blank grid board
2. Pool pixel tokens in center
3. Shuffle theme deck

## Rules
1. Reveal one theme card (e.g., "Cat", "House", "Pizza")
2. Players have 90 seconds to:
   - Grab pixels from center pool (no limit)
   - Place pixels on their grid to create the theme
3. When time expires, reveal all grids
4. Voting:
   - Each player votes for best representation (not your own)
   - Most votes = 3 points
   - Second = 2 points
   - Third = 1 point
5. Clear boards, return pixels, new theme

## Winning Condition
First to 15 points wins.

## Special Rules
- Can use empty spaces (negative space) strategically
- Limited palette: only 5 colors available
- Speed bonus: finish 30+ seconds early = +1 point (if you win votes)
- Complexity bonus: using fewer pixels effectively = +1 point
- Must be recognizable (simple stick figures acceptable)
