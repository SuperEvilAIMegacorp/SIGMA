# Rhythm Roulette

## Game Information
- **Genre**: Party/Rhythm Game
- **Players**: 3-8
- **Duration**: 15-20 minutes
- **Complexity**: 2/10 (Simple)

## Objective
Successfully replicate and add to increasingly complex rhythm patterns.

## Components
- Timer
- Rhythm cards (50 cards showing different sounds/actions)
- Score tokens

## Setup
1. Place rhythm cards face-down
2. Determine starting player

## Rules
1. First player draws a card and performs its rhythm/action once
2. Next player repeats it, then adds a new card's rhythm
3. Continue around table, each player repeating full sequence + adding one
4. If you make a mistake, you're out for the round
5. Last player remaining scores points equal to number of rhythms in sequence
6. Start new round with new player

## Winning Condition
First to 20 points wins.

## Special Rules
- Must perform rhythms accurately (table votes on disputes)
- 2-second max gap between rhythms
- Rhythms include: claps, snaps, stomps, vocal sounds
