# Rhythm Raiders

## Game Information
- **Genre**: Cooperative Rhythm Game
- **Players**: 2-6
- **Duration**: 20-30 minutes
- **Complexity**: 4/10 (Medium)

## Objective
Work together to perform rhythm sequences and defeat rhythm-based challenges.

## Components
- 60 rhythm pattern cards
- 4 instrument tokens per player
- Synchronization tracker
- Challenge deck (boss battles)
- Timer

## Setup
1. Each player chooses an instrument (drums, bass, guitar, vocals)
2. Shuffle rhythm deck
3. Draw first challenge card
4. Synchro tracker starts at 50%

## Rules
1. **Pattern Phase:**
   - Reveal rhythm cards (one per player)
   - Each card shows timing and pattern for that instrument
2. **Practice Phase:**
   - 30 seconds to coordinate
   - Can hum, tap, or gesture
3. **Performance Phase:**
   - All players perform simultaneously
   - Must stay synchronized
   - Judge rates performance (timing accuracy)
4. **Scoring:**
   - Perfect sync: +20% synchronization
   - Good: +10%
   - Poor: -10%
   - Critical fail: -25%
5. At 100% synchro, defeat challenge and move to next

## Winning Condition
Complete all 5 challenges before synchronization drops to 0%.

## Special Rules
- Each instrument has different rhythm complexity
- Combo bonus: 3 perfect performances in a row = instant challenge clear
- Special abilities per instrument:
  - Drums: set tempo (leader)
  - Bass: fill in gaps
  - Guitar: harmonize (easier sync)
  - Vocals: wild card (adapt to others)
- Difficulty scales with number of players

## Challenge Types
- Speed runs (fast tempo)
- Endurance (long patterns)
- Polyrhythms (conflicting tempos)
- Call and response
- Improvisation sections
