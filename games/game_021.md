# Crystal Collectors

## Game Information
- **Genre**: Set Collection
- **Players**: 2-4
- **Duration**: 20-25 minutes
- **Complexity**: 3/10 (Simple-Medium)

## Objective
Collect the most valuable sets of crystals.

## Components
- 60 crystal cards: 5 types, values 1-4
- Value chart showing set bonuses
- Mine deck (40 cards)

## Setup
1. Shuffle crystal deck
2. Deal 5 cards to each player
3. Reveal 3 cards face-up as the market
4. Place remaining cards as draw pile

## Rules
1. On your turn, either:
   - Draw 2 cards from draw pile, or
   - Take 1 card from market (replenish immediately), or
   - Play a set of 3+ matching crystal type for points
2. Sets score: base value × number of cards in set
3. Only one set can be played per turn

## Winning Condition
When draw pile empties, player with most points wins.

## Special Rules
- Hand limit: 8 cards
- Rainbow crystal: counts as any type in a set
- Playing 5+ of same type: double points
