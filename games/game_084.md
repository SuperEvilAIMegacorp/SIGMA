# Nexus Points

## Game Information
- **Genre**: Abstract Connection Game
- **Players**: 2-4
- **Duration**: 25-35 minutes
- **Complexity**: 6/10 (Medium-Complex)

## Objective
Control the most valuable nexus points by creating optimal connection networks.

## Components
- Hexagonal board (37 hexes)
- 60 connection markers (4 colors)
- 10 nexus tokens (numbered 1-10)
- Power calculation chart
- Territory markers

## Setup
1. Randomly place 10 nexus tokens on board
2. Each player gets 15 connection markers
3. Randomly determine turn order

## Rules
1. On your turn, place 1 connection marker on any empty edge between hexes
2. When you create a closed region (fully enclosed space):
   - Score points equal to nexus values inside that region
   - Place your territory marker
   - Nexuses in that region now contribute to your power network
3. Power network: connected territories share bonuses
4. Can block opponent connections strategically

## Winning Condition
Most points after all markers placed OR first to control 3 connected territories containing nexuses ≥5.

## Special Rules
- **Nexus Bonuses:**
  - High-value nexuses (7-10): multiply adjacent territory scores
  - Low-value nexuses (1-3): add flat bonus
  - Medium nexuses (4-6): special abilities
- **Connection Networks:**
  - Connected territories amplify each other
  - Network of 3+ territories: +10 bonus
- **Blocking:**
  - Can intentionally create small territories to deny opponents
  - Risk: uses your limited markers
- **Shared Boundaries:**
  - If two players both enclose a nexus, value splits

## Strategic Elements
- Territory size optimization
- Nexus value targeting
- Network topology
- Efficient marker usage
- Defensive vs aggressive placement
- Calculating optimal enclosures

## Advanced Variant
- Dynamic nexuses: values change based on game state
- Special abilities triggered by certain nexus combinations
- Asymmetric player powers
