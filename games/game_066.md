# DNA Sequence

## Game Information
- **Genre**: Pattern Building
- **Players**: 2-4
- **Duration**: 25-30 minutes
- **Complexity**: 5/10 (Medium)

## Objective
Build the longest valid DNA sequences using base pair rules.

## Components
- 80 base cards (A, T, G, C - 20 each)
- Sequence boards
- Pairing reference card (A-T, G-C)
- Mutation tokens
- Score tracker

## Setup
1. Shuffle base cards
2. Each player draws 7 cards
3. Place reference card visible to all
4. Each player gets 2 mutation tokens

## Rules
1. On your turn:
   - Play 1-3 base cards to build your sequence
   - Must follow pairing rules:
     * Opposite strand bases must pair correctly (A↔T, G↔C)
     * Sequences build in 5' to 3' direction
   - Draw back to 7 cards
2. Score when you complete a valid segment (both strands matched for 5+ bases)

## Winning Condition
First to 30 points wins.

## Special Rules
- Mutation tokens let you:
  - Break pairing rules once
  - Swap 3 cards with deck
- Bonus sequences:
  - Palindromic: 2x points
  - Repeating pattern: +5 bonus
  - Full hand use (all 7 cards): +10 bonus
- Can disrupt opponent sequences if you have matching blocker cards
- Advanced: add enzyme cards (special abilities)

## Scoring
- Each valid base pair: 1 point
- Complete codon (3 base pairs): +2 bonus
- Complete gene (9+ base pairs): +5 bonus
