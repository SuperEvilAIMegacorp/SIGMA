# Word Ladder

## Game Information
- **Genre**: Word Game
- **Players**: 2-4
- **Duration**: 15-20 minutes
- **Complexity**: 3/10 (Simple-Medium)

## Objective
Transform the starting word into the target word by changing one letter at a time.

## Components
- 50 word pair cards (start word → target word, same length)
- Timer (3 minutes)
- Score sheet

## Setup
1. Shuffle word pair cards
2. Determine starting player

## Rules
1. Draw one word pair card
2. Active player has 3 minutes to create a word ladder
3. Each step must be a valid English word
4. Change exactly one letter per step
5. Cannot reuse words in the same ladder
6. Score: 10 points minus number of steps (minimum 1 point)

## Winning Condition
First player to reach 30 points wins.

## Special Rules
- Other players can challenge if word is invalid
- If you can't solve in 3 minutes, pass for 0 points
- Shortest ladder for each pair earns bonus +5 points (tracked globally)

## Example
CAT → DOG: CAT → COT → DOT → DOG (3 steps = 7 points)
