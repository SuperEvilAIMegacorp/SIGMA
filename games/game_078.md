# Parallel Worlds

## Game Information
- **Genre**: Abstract Strategy
- **Players**: 2
- **Duration**: 25-30 minutes
- **Complexity**: 8/10 (Complex)

## Objective
Control more territory across multiple parallel dimensions simultaneously.

## Components
- 3 board layers (representing parallel worlds)
- 20 pieces per player
- Dimensional bridge tokens
- Portal markers
- Score tracker

## Setup
1. Stack 3 identical 5x5 grid boards
2. Each player places 3 starting pieces (one per dimension)
3. Randomly place 4 portal markers across dimensions

## Rules
1. On your turn, take 2 actions:
   - **Place:** Add piece to any dimension
   - **Move:** Move piece within dimension (orthogonal, 1-2 spaces)
   - **Bridge:** Connect pieces across dimensions (costs 1 action, limited to 5 per player)
   - **Portal:** Teleport piece through portal

2. **Dimensional Rules:**
   - Each dimension operates independently
   - Bridges allow pieces to support each other across dimensions
   - Control = most pieces in a region (4-space square)

3. **Interactions:**
   - Pieces on same space across dimensions can't be placed
   - Bridges block opponent bridges
   - Portals create strategic shortcuts

## Winning Condition
After all pieces placed, player controlling most regions across all dimensions wins.

## Special Rules
- 3D thinking required: visualize across layers
- Bridges multiply scoring (connected regions = 2x points)
- Portal control: if you control both ends of portal, +5 bonus
- Dimensional collapse: if one dimension has 10+ pieces, remove all pieces (reset that layer)
- Advanced: add 4th dimension (time) - pieces can move backward/forward in game history

## Strategic Depth
- Multi-dimensional planning
- Resource allocation across dimensions
- Bridge network optimization
- Portal control vs expansion
- Defensive vs aggressive positioning
