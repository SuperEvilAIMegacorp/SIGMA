# Tile Kingdoms

## Game Information
- **Genre**: Territory Building
- **Players**: 2-4
- **Duration**: 35-45 minutes
- **Complexity**: 6/10 (Medium-Complex)

## Objective
Build the most valuable kingdom by strategically placing terrain tiles.

## Components
- 72 terrain tiles (6 types: forest, plains, mountains, water, desert, villages)
- 4 castle tokens (one per player)
- Scoring reference card

## Setup
1. Each player places their castle on table as starting tile
2. Shuffle terrain tiles face-down
3. Each player draws 3 tiles as starting hand

## Rules
1. On your turn:
   - Play one tile adjacent to your kingdom (must share full edge)
   - Score points based on tile placement:
     * Same terrain adjacent: +1 point per matching tile
     * Villages adjacent to 3+ different terrains: +5 points
     * Mountains adjacent to water: +3 points
     * Complete 4x4 square of any tiles: +10 points
   - Draw one new tile
2. Kingdoms can grow in any direction

## Winning Condition
When all tiles are played, player with most points wins.

## Special Rules
- Castle counts as village for scoring
- Terrain-specific bonuses stack
- Some tiles have special icons (quarries, harbors) for extra rules
