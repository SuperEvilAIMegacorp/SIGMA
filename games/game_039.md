# Maze Runners

## Game Information
- **Genre**: Racing Game
- **Players**: 2-4
- **Duration**: 25-30 minutes
- **Complexity**: 4/10 (Medium)

## Objective
Navigate your maze and reach the exit first.

## Components
- 4 individual maze boards (one per player)
- Movement dice (d6 with directions: N, S, E, W, ↺, ⚡)
- Wall tokens
- Player pawns

## Setup
1. Each player receives a maze board
2. Build walls on your board using 12 wall tokens (strategic placement)
3. Place pawn at start position
4. Decide maze complexity (more walls = harder)

## Rules
1. All players roll simultaneously
2. Move your pawn according to die result:
   - **N/S/E/W:** Move 1 space in that direction if no wall blocks
   - **↺:** Rotate die and move in new direction
   - **⚡:** Move 2 spaces in any direction (ignore 1 wall)
3. If blocked by wall, stay in place
4. Can't move through board edges

## Winning Condition
First player to reach their exit wins.

## Special Rules
- Players can't see others' maze layouts
- Dead ends: if surrounded by walls, teleport to start
- Secret passages: two special tokens allow wall-passing (1-time use)
- Can rebuild walls once mid-game (costs 2 turns)
