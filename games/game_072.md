# Paradox Protocol

## Game Information
- **Genre**: Cooperative Puzzle
- **Players**: 2-4
- **Duration**: 40-50 minutes
- **Complexity**: 8/10 (Complex)

## Objective
Solve interconnected logic puzzles to prevent temporal paradoxes.

## Components
- 30 paradox cards (each a logic puzzle)
- Timeline board (branching paths)
- Solution tokens
- Causality tracker
- Hint cards (limited)

## Setup
1. Arrange timeline board with 3 branching paths
2. Place paradox cards at decision points
3. Each path has 10 decision nodes
4. Causality tracker starts at 100%

## Rules
1. **Decision Phase:**
   - Team examines current paradox card
   - Puzzle types: logic grids, pattern completion, constraint satisfaction
2. **Solution Phase:**
   - Team discusses and proposes solution (5 minute limit)
   - Place solution token
3. **Verification Phase:**
   - Check solution against answer key
   - Correct: advance on timeline, +5% causality
   - Incorrect: -15% causality, must retry or skip
4. **Consequence Phase:**
   - Some puzzles affect future puzzles (branching logic)
   - Wrong answers create contradictions later

## Winning Condition
Reach end of any timeline path with >50% causality.

## Special Rules
- Branching timelines: early decisions affect later puzzle availability
- Paradox chains: solving certain puzzles in sequence provides bonus information
- Hint system: spend 10% causality for hint
- Some puzzles have multiple valid solutions (different timeline branches)
- Meta-puzzle: pattern across all puzzles reveals shortcut

## Puzzle Categories
- Temporal ordering (A before B before C)
- Logic grids (assign attributes to entities)
- Pattern recognition (next in sequence)
- Constraint satisfaction (assign values meeting all rules)
- Graph theory (paths and networks)

## Difficulty Scaling
Easy: individual puzzles independent
Hard: puzzles interconnect, solutions constrain each other
