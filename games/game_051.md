# Paradox Engine

## Game Information
- **Genre**: Logic Puzzle
- **Players**: 1-4 (cooperative)
- **Duration**: 35-45 minutes
- **Complexity**: 8/10 (Complex)

## Objective
Solve time paradoxes by creating consistent timeline loops.

## Components
- 50 event cards (each with timestamp and effects)
- Timeline board (20 time slots)
- Causality tokens
- Paradox tracker
- Solution reference (sealed)

## Setup
1. Draw 10 random event cards
2. Place on timeline in random order
3. Paradox tracker starts at 0

## Rules
1. **Analysis Phase:** Examine event cards
2. **Rearrangement Phase:**
   - Move cards to different time slots
   - Goal: eliminate contradictions
3. **Verification Phase:**
   - Check causality chains
   - Each contradiction = +1 paradox
4. Causality rules:
   - Event A can cause Event B only if A occurs before B
   - Effects must have prior causes
   - No circular causality (A→B→C→A)

## Winning Condition
Reduce paradox count to 0.

## Special Rules
- Some events have multiple possible causes
- Advanced: add time travel cards that bend rules
- Certain event pairs always create paradoxes (must choose one to remove)
- Hint tokens: reveal one correct placement (3 available)

## Example Paradox
Event 5: "Receive warning message"
Event 8: "Send warning message"
Problem: Can't receive before sent → must reorder
