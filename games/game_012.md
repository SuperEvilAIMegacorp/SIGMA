# Auction House

## Game Information
- **Genre**: Auction Game
- **Players**: 3-6
- **Duration**: 30-40 minutes
- **Complexity**: 5/10 (Medium)

## Objective
Collect the most valuable set of items through strategic bidding.

## Components
- 50 item cards (various values 1-10)
- Starting money: 100 coins per player
- Auctioneer token

## Setup
1. Give each player 100 coins
2. Shuffle item deck
3. Randomly determine first auctioneer

## Rules
1. Auctioneer reveals top 3 items
2. Players bid on items one at a time (ascending bid auction)
3. Highest bidder pays their bid and takes the item
4. Auctioneer rotates clockwise after each set of 3 items
5. Certain items create sets that multiply in value

## Winning Condition
After all items are auctioned, player with highest total value (items + remaining money) wins.

## Special Rules
- Minimum bid: 1 coin
- If you cannot pay your bid, you're eliminated
- Set bonuses: 3 of same type = 2x value, 5 of same type = 3x value
- Auctioneer cannot bid on items they're auctioning
