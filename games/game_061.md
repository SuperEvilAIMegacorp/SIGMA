# Mirror Match

## Game Information
- **Genre**: Memory & Pattern Matching
- **Players**: 2-4
- **Duration**: 15-20 minutes
- **Complexity**: 3/10 (Simple-Medium)

## Objective
Recreate mirrored patterns from memory accurately.

## Components
- 2 grid boards per player (pattern board & recreation board)
- 60 colored tokens (6 colors, 10 each)
- Pattern cards (40)
- Timer (30 seconds)
- Privacy screens

## Setup
1. Each player gets 2 boards and privacy screen
2. Shuffle pattern cards
3. Pool colored tokens

## Rules
1. Reveal one pattern card showing colored token arrangement (2-7 tokens)
2. All players study it for 30 seconds
3. Hide pattern card
4. Players have 60 seconds to:
   - Recreate pattern on their recreation board
   - Must be mirror image (flipped horizontally)
5. Reveal and score:
   - Each correct token placement = 1 point
   - Perfect mirror = bonus +3 points
   - Wrong color/position = 0 points

## Winning Condition
First to 25 points wins.

## Special Rules
- Difficulty scales: patterns get more complex
- Rotating patterns: some cards require 90° rotation instead of mirror
- Memory challenge: advanced mode gives only 15 seconds to study
- Partial credit: correct colors in wrong positions = 0.5 points each

## Pattern Complexity Levels
- Simple: 2-3 tokens, basic shapes
- Medium: 4-5 tokens, symmetrical
- Hard: 6-7 tokens, asymmetrical
- Expert: 8+ tokens with specific spacing
