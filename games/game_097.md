# Cipher Clash

## Game Information
- **Genre**: Word/Deduction Game
- **Players**: 2-4 (teams of 2 recommended)
- **Duration**: 30-40 minutes
- **Complexity**: 5/10 (Medium)

## Objective
Decode secret messages faster than opponents while protecting your own codes.

## Components
- 100 letter tiles
- Encryption wheels (cipher devices)
- 40 message cards (phrases to encode)
- Decoder sheets
- Timer (60 seconds per round)
- Hint tokens (3 per team)

## Setup
1. Each player/team gets encryption wheel
2. Draw 3 message cards (keep secret)
3. Each team draws 7 letter tiles
4. Place hint tokens

## Rules
**Round Structure:**
1. **Encoding Phase:**
   - Choose one message card
   - Encode it using letter tiles and cipher
   - Place encoded message face-up
2. **Decoding Phase:**
   - All opponents have 60 seconds
   - Try to decode opponent messages
   - Use decoder sheets to track attempts
3. **Scoring:**
   - Correct decode: +5 points
   - Your message undecoded: +3 points
   - Partial decode (50%+ words): +2 points

## Cipher Types
Players can choose encryption method:
- **Caesar Shift:** Shift letters by N positions
- **Substitution:** Random letter replacement
- **Keyword Cipher:** Use keyword to create alphabet
- **Reversals:** Write backwards or mirror
- **Atbash:** Reverse alphabet substitution

## Winning Condition
First team to 30 points OR most points after 10 rounds.

## Special Rules
- **Hint Tokens:**
  - Spend 1 to reveal one letter's cipher
  - Spend 2 to reveal cipher type used
  - Spend 3 to get full 30-second extension
- **Cipher Complexity:**
  - Simple ciphers: easier to crack but less defense points
  - Complex ciphers: harder to crack but harder to create
- **Letter Tiles:**
  - Limited supply creates constraints
  - Must work with available letters
  - Can request vowel/consonant trade (costs 1 point)
- **Double Encoding:**
  - Can apply two cipher types
  - Nearly impossible to crack but costs extra time

## Strategic Elements
- Cipher selection (security vs speed)
- Message selection (long vs short)
- Hint token economy
- Pattern analysis
- Frequency analysis techniques
- Teamwork (if playing in teams)

## Difficulty Scaling
- Beginner: Use only Caesar shift
- Intermediate: Allow 3 cipher types
- Expert: All ciphers + double encoding
- Master: Add numerical ciphers and symbols

## Educational Value
- Learn cryptography basics
- Pattern recognition
- Problem solving
- Logical deduction
