# Prophecy Tokens

## Game Information
- **Genre**: Betting/Prediction
- **Players**: 3-6
- **Duration**: 25-35 minutes
- **Complexity**: 4/10 (Medium)

## Objective
Score the most points by making accurate predictions about random events.

## Components
- 50 event cards (various random scenarios)
- Prediction tokens (betting chips)
- Outcome dice/cards (varies by event)
- Confidence board (betting track)
- Score tracker

## Setup
1. Each player starts with 20 prediction tokens
2. Shuffle event deck
3. Set scores to 0

## Rules
1. **Event Reveal:**
   - Flip top event card
   - Examples:
     * "Will the sum of 3 dice be odd or even?"
     * "Will the next card be red or black?"
     * "Will player to your left answer trivia correctly?"
2. **Prediction Phase:**
   - All players secretly place prediction tokens on outcomes
   - Can bet on multiple outcomes
   - More tokens = more confident
3. **Resolution Phase:**
   - Resolve event (roll dice, draw card, etc.)
   - Winners double their bet
   - Losers lose bet tokens
4. **Scoring:**
   - After 15 events, exchange tokens for points (1:1)

## Winning Condition
Most tokens/points at game end.

## Special Rules
- **Confidence Betting:**
  - Can bet 1-5 tokens on single outcome
  - Higher bet = higher reward but more risk
- **Insurance:**
  - Spend 1 token to protect up to 3 tokens from loss (one time use per round)
- **All-in:**
  - Bet all remaining tokens = triple reward if correct
- **Bankrupt:**
  - If you reach 0 tokens, get 5 "loan" tokens (-5 final score)
- **Event Types:**
  - Pure chance (dice, cards)
  - Social (predictions about other players)
  - Trivia (knowledge-based)
  - Skill (quick challenges)

## Strategic Elements
- Probability calculation
- Risk management
- Token preservation vs aggression
- Reading other players
- Event type pattern recognition

## Variants
- Team mode: partners share tokens
- Progressive jackpot: unclaimed tokens carry over
- Chaos mode: random multipliers on events
