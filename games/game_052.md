# Emoji Story

## Game Information
- **Genre**: Creative Party Game
- **Players**: 3-8
- **Duration**: 20-30 minutes
- **Complexity**: 2/10 (Simple)

## Objective
Create the most entertaining story using only emoji cards.

## Components
- 120 emoji cards (various categories)
- Story prompt cards (30)
- Voting tokens
- Timer (2 minutes)

## Setup
1. Shuffle emoji deck
2. Deal 7 emoji cards to each player
3. Draw one story prompt

## Rules
1. Read story prompt aloud (e.g., "Tell the story of how you lost your keys")
2. Players have 2 minutes to arrange their 7 emojis in sequence
3. Each player presents their emoji story (can elaborate verbally while pointing)
4. All players vote on best story (can't vote for self)
5. Winner gets 1 point
6. Draw new prompt, deal new hands

## Winning Condition
First to 5 points wins.

## Special Rules
- Must use all 7 emojis in order
- Can draw 2 additional emojis for -1 point
- "Wild emoji" cards can represent anything
- Audience participation: bonus point if everyone laughs

## Emoji Categories
- Faces/emotions
- Objects
- Animals
- Actions
- Symbols
- Food
