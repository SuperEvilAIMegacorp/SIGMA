# Bridge Builder

## Game Information
- **Genre**: Spatial Puzzle
- **Players**: 1-4 (competitive or cooperative)
- **Duration**: 20-30 minutes
- **Complexity**: 5/10 (Medium)

## Objective
Build bridges connecting all islands using limited pieces.

## Components
- Island tiles (12 different configurations)
- 60 bridge pieces (3 lengths: short, medium, long)
- Blueprint cards showing target configurations
- Score tracker

## Setup
1. Draw one blueprint card showing island layout
2. Arrange islands as shown on blueprint
3. Pool all bridge pieces
4. Each player gets building mat (competitive mode)

## Rules
**Competitive Mode:**
1. All players build simultaneously using shared pieces (first come, first serve)
2. Must connect all islands in your network
3. Bridges must span gaps exactly (no overhang)
4. First to complete valid network wins round
5. Play 5 rounds

**Cooperative Mode:**
1. Team works together to find optimal solution
2. Goal: use fewest pieces possible

## Winning Condition
**Competitive:** Win most rounds
**Cooperative:** Beat the target piece count

## Special Rules
- Bridges cannot cross each other
- Each island has 2-4 connection points
- Some blueprints have obstacles/restricted zones
